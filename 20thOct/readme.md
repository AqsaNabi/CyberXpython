## Topics Learned

### 1. Generative AI
- **Overview of Generative AI:** Learned the basics of Generative AI and how it generates new content such as text, images, audio, and video.
- **How Generative AI Works:** Studied the basic process through which generative models learn patterns from training data to generate new outputs.
- **Tuning and Fine-Tuning:** Learned how model parameters and training processes can be adapted to improve performance for specific tasks.
- **Reinforcement Learning from Human Feedback (RLHF):** Learned how human feedback is used to help align a model's responses with human preferences.

### 2. Generative AI Model Architectures
- **Evolution of Generative AI Architectures:** Explored how generative model architectures have developed over time.
- **Generative Adversarial Networks (GANs):** Learned how a generator creates synthetic data while a discriminator tries to distinguish generated data from real data.
- **Variational Autoencoders (VAEs):** Studied how VAEs learn a probabilistic latent representation of data and generate new samples from it.
- **Diffusion Models:** Learned the basic concept of gradually adding noise to data and learning to reverse the process to generate new samples.
- **Transformers (Basic Introduction):** Read an introductory overview of Transformers, why they are used, and their role in modern Generative AI. This topic was not covered in detail.

### 3. Feature Engineering
- **Overview and Importance:** Learned how feature engineering improves the quality and usefulness of input data for machine learning models.

### 4. Data Preprocessing and Feature Engineering Techniques
- **Imputation:** Learned how missing values are handled in datasets.
- **Categorical Imputation:** Studied methods for filling missing values in categorical features, such as using the mode or a separate category.
- **Handling Outliers:** Explored methods for dealing with outliers, including removal and replacing extreme values.
- **Feature Scaling:** Learned how to bring numerical features to comparable scales.
- **Discretization:** Studied how continuous numerical values can be grouped into discrete intervals.
- **Log Transformation:** Learned how logarithmic transformations can reduce skewness in numerical data.
- **Encoding:** Studied how categorical variables are converted into numerical representations.
- **Feature Splitting:** Learned how to separate existing features into meaningful components.
- **Feature Creation:** Studied how to create new features from existing data to help models learn useful patterns.
