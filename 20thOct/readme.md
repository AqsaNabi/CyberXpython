 <h2>Topics Learned</h2>

<h3>1. Generative AI</h3>

<p><b>Overview of Generative AI:</b> Learned the basics of Generative AI and how it generates new content such as text, images, audio, and video.</p>

<p><b>How Generative AI Works:</b> Learned how generative models identify patterns in training data to generate new outputs.</p>

<p><b>Tuning and Fine-Tuning:</b> Studied how models can be adapted to improve their performance for specific tasks.</p>

<p><b>Reinforcement Learning from Human Feedback (RLHF):</b> Learned how human feedback helps align model responses with human preferences.</p>

<h3>2. Generative AI Model Architectures</h3>

<ul>
<li><b>GANs:</b> Learned how a generator creates synthetic data while a discriminator distinguishes generated data from real data.</li>
<li><b>Variational Autoencoders (VAEs):</b> Studied how VAEs learn latent representations and generate new samples.</li>
<li><b>Diffusion Models:</b> Learned how these models generate data by reversing a gradual noise-adding process.</li>
<li><b>Transformers:</b> Read a basic introduction to Transformers, why they are used, and their role in Generative AI. This topic was not covered in detail.</li>
</ul>

<h3>3. Feature Engineering and Data Preprocessing</h3>

<ul>
<li><b>Feature Engineering:</b> Learned its importance in improving the quality of input data for machine learning models.</li>
<li><b>Imputation:</b> Studied techniques for handling missing values.</li>
<li><b>Categorical Imputation:</b> Learned methods for filling missing categorical values.</li>
<li><b>Handling Outliers:</b> Explored removal and replacement methods for extreme values.</li>
<li><b>Feature Scaling:</b> Learned how to bring numerical features to comparable scales.</li>
<li><b>Discretization:</b> Studied how continuous values can be grouped into intervals.</li>
<li><b>Log Transformation:</b> Learned how logarithmic transformations can reduce skewness.</li>
<li><b>Encoding:</b> Studied how categorical values are converted into numerical representations.</li>
<li><b>Feature Splitting and Creation:</b> Learned how to split existing features into components and create new features from existing data.</li>
</ul>
