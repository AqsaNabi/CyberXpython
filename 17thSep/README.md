<h2>Pydantic</h2>
Today I practiced <b>Pydantic</b> by creating a <b>patient model</b> and using different validation and data-handling features in one example. I started by creating an <b>AAddress nested model</b> with <b>city</b>, <b>state</b>, and <b>pin</b>, and then used this model as the <b>address field</b> inside the patient model. In the patient model, I used different <b>data types</b> such as <b>string</b>, <b>integer</b>, <b>float</b>, <b>boolean</b>, <b>EmailStr</b>, and <b>AnyUrl</b>. I also practiced <b>Optional</b>, <b>List</b>, <b>Dict</b>, and <b>Annotated</b> for different fields. For the <b>name field</b>, I used <b>Annotated with Field</b> and added a maximum length along with title, description, and example information. For the <b>age</b> field, I added validation using <b>Field(gt=0, lt=100)</b>, and for <b>weight</b> I added a condition that the value should be greater than zero. I used an <b>optional list for allergies</b> and added a maximum length of five, and I used a <b>dictionary for contact_details</b> to store the patient's contact information. I also added a <b>URL field</b> using <b>AnyUrl</b>. After that, I created a <b>field validator for email</b> using <b>@field_validator</b> and checked whether the email domain belongs to the allowed domains, which were <b>hdfc.com</b> and <b>icici.com</b>. I created another <b>field validator for the name</b> and used it to convert the patient's name into uppercase. I also practiced <b>model validation</b> using <b>@model_validator(mode='after')</b>, where I checked the patient's age and contact details together and made sure that an emergency contact was present for patients above 60. I created a <b>computed field</b> called <b>calculated_bmi</b> using <b>@computed_field</b> and <b>@property</b> and then printed the calculated value along with the other patient information. I created functions for <b>displaying patient data</b> and <b>updating patient data</b>, and then created the patient object by passing a dictionary using <b>**patient_info</b>. I also tested Pydantic's data conversion by providing the age as a string value and using it in the model as an integer. After creating the patient object, I accessed the nested address data using <b>p1.address.pin</b>. Finally, I practiced <b>model_dump()</b> and used <b>include</b> to get only the name and <b>exclude</b> to remove the name from the output, and I also checked the type of the dumped data. So today I mainly worked on <b>Pydantic models, nested models, data types, Field validation, field validators, model validators, computed fields, optional and list fields, dictionary fields, URL and email validation, data conversion, nested data access, and model_dump()</b> by implementing them in a single patient example.
