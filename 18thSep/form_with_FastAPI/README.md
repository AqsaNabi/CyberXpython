In this project i have used <b>FastAPI</b> to handle student form submissions and retrieve stored student data. The information entered through the form is collected using the <b>POST</b> method and stored in a <b>students.json</b> file in JSON format. The <b>POST</b> method is used to receive the student details after the form is submitted, including name, parent details, gender, date of birth, email, level, department, and phone number, and then append the submitted data to the JSON file. The <b>GET</b> method is used to retrieve and display all the student data currently stored in the <b>students.json</b> file. This provides a simple way to submit, store, and retrieve student information using FastAPI and JSON.
