This project focuses on learning the basics of <b>Streamlit Session State</b> and understanding how Streamlit stores and maintains values between application reruns. While implementing this application, I learned how to access the <b>st.session_state</b> object, initialize session-state variables using conditions such as <b>if 'key' not in st.session_state</b>, and store different types of values such as integers and Boolean values in session state. I learned how to access stored values using both <b>st.session_state["key"]</b> and <b>st.session_state.key</b>, and how to iterate through <b>session_state.keys()</b> and <b>session_state.values()</b> to display stored keys and their corresponding values. I also learned how to remove individual session-state values using the <b>del</b> statement and how deleting keys can be used to clear session-state data. Another important concept I learned was <b>connecting Session State with Streamlit widgets</b>, where assigning a key such as <b>key="slider"</b> to a slider automatically stores the widget's value inside <b>st.session_state</b>. Overall, this implementation helped me understand how <b>Session State maintains application data, manages widget values, stores variables across reruns, and allows interactive Streamlit applications to keep track of user state</b>.

I also created a basic authentication system using Streamlit and Python i.e <b>login_auth.py</b>. I stored the user IDs, names, and passwords in a JSON file and used Python to read the data from the file. I created a login page where the user enters their ID and password, and I checked the entered credentials against the data stored in the JSON file. If the credentials match, I display a success message and show the form after successful authentication. If the credentials do not match, I display an error message and do not show the form.
